# RESTAURANT-RECIEPT-_-Java-project
This project is designed to generate a restaurant receipt using java. It calculates items prices, quantities, taxes, the  overall total, and the customer's  balance.
# WHAT THE PROGRAM DOES
The program prompts the user to enter the cashier's name , date, order number, and the amount paid by the customer in Ghana cedis (GHS). It also collects the descriptions, quantities, and prices of the items ordered.


# Technologies and Concept Used
## A for loop:  used to allow the user to enter multiple items,
## User-Defined Methods: are used to calculate the different taxes, including VAT,NHIL,GetFund,COVID-19 Levy, Tourism Levy, and Elevy.

## Arithmetic Operations: Used to calculate items totals, taxes, the overall total and the customer's balance and displays the information in a receipt format. 

## Scanner Class: Used to collect input from the user. 

# Output 
The program displays a well-organized restaurant receipt containing all the entered information and calculated amounts.
